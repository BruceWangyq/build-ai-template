## 🚀 方式一：Docker 一键部署（推荐）

这是最简单快速的部署方式，适合快速体验和生产环境使用。

### 前置要求

- Docker >= 26.0
- Docker Compose >= 2.25

### 部署步骤

1. **克隆项目**

```bash
git clone https://github.com/open-v2ai/build-ai-template.git
cd build-ai-template/deploy/
```

2. **配置环境变量**

```bash
# 复制环境变量模板
cp .env.example .env

# 编辑环境变量文件
nano .env  # 或使用您喜欢的编辑器
```

**必需配置项**：

```bash
# AI 配置（必填）
AGENT_API_KEY=sk-proj-your-openai-api-key
AGENT_BASE_URL=https://api.openai.com/v1
AGENT_MODEL_NAME=gpt-4o-mini

# 邮件配置（必填，用于登录验证码）
MAIL_USERNAME=your-email@gmail.com
MAIL_PASSWORD=your-app-password
MAIL_FROM=your-email@gmail.com
MAIL_SERVER=smtp.gmail.com
MAIL_PORT=587

# 安全配置（建议修改）
AUTH_SECRET_KEY=your-super-secret-key-here
```

<Alert>
  <AlertTitle>📧 邮件配置说明</AlertTitle>
  <AlertDescription>
    <div className="mt-2 space-y-2">
      <p><strong>Gmail 用户</strong>：需要开启两步验证并生成应用专用密码</p>
      <p><strong>其他邮箱</strong>：请参考邮箱服务商的 SMTP 配置文档</p>
      <p><strong>测试环境</strong>：可以使用 <code>AUTH_DEBUG_CODE=888888</code> 跳过邮件验证</p>
    </div>
  </AlertDescription>
</Alert>

3. **启动服务**

```bash
# 一键启动所有服务
docker compose up -d

# 查看服务状态
docker compose ps

# 查看日志（可选）
docker compose logs -f
```

4. **访问应用**

- **用户界面**：http://localhost:8080
- **管理后台**：http://localhost:8080/admin
- **API 文档**：http://localhost:8080/api/docs

  <AlertDescription>
    第一个通过邮箱验证登录的用户将自动获得管理员权限！
  </AlertDescription>
</Alert>

## 🛠️ 方式二：开发环境运行

适合开发者进行功能开发和定制。

### 前置要求

- **后端**：Python >= 3.12，uv >= 0.6
- **前端**：Node.js >= 18.19，pnpm >= 10.11
- **数据库**：PostgreSQL 和 Redis

### 步骤 1：准备数据库

```bash
# 克隆项目
git clone https://github.com/open-v2ai/build-ai-template.git
cd build-ai-template

# 启动 PostgreSQL（使用 Docker）
bash api/scripts/run_postgres.sh

# 启动 Redis（使用 Docker）
bash api/scripts/run_redis.sh
```

### 步骤 2：配置并运行后端

```bash
cd api/

# 安装依赖
uv sync

# 激活虚拟环境
source venv/bin/activate  # Linux/macOS
# 或 venv\Scripts\activate  # Windows

# 配置环境变量
cp .env.example .env
# 编辑 .env 文件，配置数据库连接、AI API Key 等

# 运行数据库迁移
alembic upgrade head

# 启动开发服务器（端口 8000）
python -m app.main
```

### 步骤 3：配置并运行前端

```bash
# 新开终端窗口
cd web/

# 安装依赖
pnpm install

# 创建并配置环境变量文件
touch .env
```

**创建 `web/.env` 文件**并填入以下内容：

```bash
# 后端 API 服务器的 URL
NEXT_PUBLIC_API_URL=http://localhost:8000
```

然后，启动开发服务器：

```bash
# 启动开发服务器（端口 3000）
pnpm dev
```

### 步骤 4：访问应用

- **用户界面**：http://localhost:3000
- **管理后台**：http://localhost:3000/admin
- **API 文档**：http://localhost:8000/docs

## ✅ 验证部署

### 1. 检查服务状态

```bash
# Docker 部署
docker compose ps

# 开发环境
curl http://localhost:8000/health  # 后端健康检查
curl http://localhost:3000         # 前端访问
```

### 2. 测试核心功能

1. **用户注册登录**
   - 访问应用首页
   - 点击登录，输入邮箱
   - 检查邮箱验证码（或使用调试码 888888）

2. **AI 对话测试**
   - 登录后创建新对话
   - 发送测试消息
   - 验证 AI 响应和流式显示

3. **管理后台访问**
   - 访问 `/admin` 路径
   - 查看用户管理、对话统计等功能
