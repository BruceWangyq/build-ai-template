## 🚀 Method 1: Docker One-Click Deployment (Recommended)

This is the simplest and fastest deployment method, suitable for quick experience and production environment use.

### Prerequisites

- Docker >= 26.0
- Docker Compose >= 2.25

### Deployment Steps

1. **Clone the Project**

```bash
git clone https://github.com/open-v2ai/build-ai-template.git
cd build-ai-template/deploy/
```

2. **Configure Environment Variables**

```bash
# Copy environment variable template
cp .env.example .env

# Edit environment variable file
nano .env  # or use your preferred editor
```

**Required Configuration**:

```bash
# AI Configuration (Required)
AGENT_API_KEY=sk-proj-your-openai-api-key
AGENT_BASE_URL=https://api.openai.com/v1
AGENT_MODEL_NAME=gpt-4o-mini

# Email Configuration (Required for login verification codes)
MAIL_USERNAME=your-email@gmail.com
MAIL_PASSWORD=your-app-password
MAIL_FROM=your-email@gmail.com
MAIL_SERVER=smtp.gmail.com
MAIL_PORT=587

# Security Configuration (Recommended to modify)
AUTH_SECRET_KEY=your-super-secret-key-here
```

<Alert>
  <AlertTitle>📧 Email Configuration Instructions</AlertTitle>
  <AlertDescription>
    <div className="mt-2 space-y-2">
      <p><strong>Gmail Users</strong>: Need to enable two-factor authentication and generate an app-specific password</p>
      <p><strong>Other Email Providers</strong>: Please refer to your email service provider's SMTP configuration documentation</p>
      <p><strong>Test Environment</strong>: You can use <code>AUTH_DEBUG_CODE=888888</code> to skip email verification</p>
    </div>
  </AlertDescription>
</Alert>

3. **Start Services**

```bash
# Start all services with one command
docker compose up -d

# Check service status
docker compose ps

# View logs (optional)
docker compose logs -f
```

4. **Access Application**

- **User Interface**: http://localhost:8080
- **Admin Panel**: http://localhost:8080/admin
- **API Documentation**: http://localhost:8080/api/docs

<Alert>
  <AlertTitle>🎉 First Login Tip</AlertTitle>
  <AlertDescription>
    The first user to log in via email verification will automatically receive administrator privileges!
  </AlertDescription>
</Alert>

## 🛠️ Method 2: Development Environment Setup

Suitable for developers to perform feature development and customization.

### Prerequisites

- **Backend**: Python >= 3.12, uv >= 0.6
- **Frontend**: Node.js >= 18.19, pnpm >= 10.11
- **Database**: PostgreSQL and Redis

### Step 1: Prepare Database

```bash
# Clone the project
git clone https://github.com/open-v2ai/build-ai-template.git
cd build-ai-template

# Start PostgreSQL (using Docker)
bash api/scripts/run_postgres.sh

# Start Redis (using Docker)
bash api/scripts/run_redis.sh
```

### Step 2: Configure and Run Backend

```bash
cd api/

# Install dependencies
uv sync

# Activate virtual environment
source venv/bin/activate  # Linux/macOS
# or venv\Scripts\activate  # Windows

# Configure environment variables
cp .env.example .env
# Edit .env file, configure database connection, AI API Key, etc.

# Run database migrations
alembic upgrade head

# Start development server (port 8000)
python -m app.main
```

### Step 3: Configure and Run Frontend

```bash
# Open new terminal window
cd web/

# Install dependencies
pnpm install

# Configure environment variables
cp .env.example .env
# Edit .env file

# Start development server (port 3000)
pnpm dev
```

### Step 4: Access Application

- **User Interface**: http://localhost:3000
- **Admin Panel**: http://localhost:3000/admin
- **API Documentation**: http://localhost:8000/docs

## ✅ Verify Deployment

### 1. Check Service Status

```bash
# Docker deployment
docker compose ps

# Development environment
curl http://localhost:8000/health  # Backend health check
curl http://localhost:3000         # Frontend access
```

### 2. Test Core Features

1. **User Registration and Login**
   - Visit the application homepage
   - Click login and enter email
   - Check email verification code (or use debug code 888888)

2. **AI Chat Testing**
   - Create a new conversation after login
   - Send test messages
   - Verify AI responses and streaming display

3. **Admin Panel Access**
   - Visit `/admin` path
   - View user management, conversation statistics, and other features
